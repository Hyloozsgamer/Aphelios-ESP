# 🛡️ Sinergias y Composiciones de Equipo

Aphelios no puede jugar solo. Es dependiente en gran medida de sus aliados para protegerle e iniciar peleas mientras él aplica el daño de área.

## ⚔️ Composiciones Ideales (5v5)

La alineación ideal para jugar Aphelios es la composición **Front-To-Back** clásica:
1. **Toplane:** Tanque/Bruiser iniciador (Ornn, Sion, Sett).
2. **Jungla:** Control / Peel (Sejuani, Ivern, Maokai).
3. **Midlane:** Mago de Control (Orianna, Azir, Viktor) para dominar el espacio y hacer "Wombo Combo".
4. **Support:** Enchanter o Engage pesado (Thresh, Lulu, Braum).

Si tu equipo son 4 Asesinos (Ej: Teemo, Kha'Zix, Zed, Pyke), Aphelios no brillará porque no tendrá una barrera humana para protegerlo mientras hace el daño en las Teamfights.

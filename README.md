## <img src="https://ddragon.leagueoflegends.com/cdn/14.18.1/img/item/3364.png" width="20" style="vertical-align: middle;"> Introducción: El Sistema de Decisiones

**NO leas esta guía esperando aprender "combos mecánicos".**
Aphelios no es un campeón de memorización muscular. Es un sistema dinámico. Si juegas en piloto automático, estás jugando en inferioridad. Cada click que haces debe ser una respuesta calculada a la función matemática del estado actual de la partida.

**Tu decisión de posicionamiento es el resultado de:**
`F(Armas actuales, Munición, Siguiente arma, Posición del Enemigo, Distancia, Cooldowns Enemigos, Niebla de Guerra, Oleada, Terreno, Estado de Aliados)`
